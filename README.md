# R1XON CHECKER

Проверка компьютера перед запуском продукта R1XON. Выберите продукт — чекер сверит настройки Windows, оборудование и необходимые компоненты с его требованиями, а затем покажет результат и понятные следующие шаги.

**[Скачать для Windows x64](https://github.com/R1Xon1/R1XON-CHECKER-RELEASES/releases/latest/download/R1XON-CHECKER.exe)** · [Все версии и сборка x86](https://github.com/R1Xon1/R1XON-CHECKER-RELEASES/releases/latest)

- Один EXE: установка программы, .NET и отдельные DLL не нужны.
- Windows 10 начиная с версии 1809 и Windows 11; русский и английский интерфейс.
- Результаты по выбранному продукту, отдельные состояния античитов и официальные ссылки на недостающие компоненты.
- Отчёт можно скопировать одной кнопкой или открыть папку с сохранёнными отчётами.
- Чекер только читает настройки. Данные о ПК и результаты проверки автоматически никуда не передаются и сохраняются на вашем компьютере.
- Сборка x64 проверяет новую версию на GitHub. Установка обновления начинается только по нажатию; подпись манифеста и целостность файла проверяются перед заменой.

Этот репозиторий содержит готовые выпуски программы. Исходный код приложения не публикуется.
