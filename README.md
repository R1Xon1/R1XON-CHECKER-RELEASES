# R1XON CHECKER

R1XON CHECKER проверяет, соответствует ли компьютер требованиям выбранного продукта: настройки Windows, оборудование, необходимые компоненты и возможные конфликты с другими программами.

**[Скачать для Windows x64](https://github.com/R1Xon1/R1XON-CHECKER-RELEASES/releases/latest/download/R1XON-CHECKER.exe)** · [Для 32-битной Windows](https://github.com/R1Xon1/R1XON-CHECKER-RELEASES/releases/latest/download/R1XON-CHECKER-win-x86.exe)

Запустите чекер, выберите продукт и нажмите «Проверить компьютер». После проверки вы увидите, что требует внимания. Если нужна помощь, скопируйте отчёт для поддержки или откройте папку с сохранёнными отчётами.

Установка не нужна — достаточно одного EXE. Поддерживаются Windows 10 от версии 1809 и Windows 11. Интерфейс доступен на русском и английском.

Чекер не изменяет настройки системы. Данные о компьютере и результаты проверки сохраняются на вашем ПК и автоматически никуда не отправляются.
